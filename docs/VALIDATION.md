# Validation

Verified on 2026-11-02 using Xcode 27.2, Swift 6.4.2 and an iPhone 17 Pro Simulator with iOS 26.5. The app's deployment target is iOS 17.0; a physical-device run and older-runtime testing are still required before distribution.

- `swift test`: 12 tests passed, zero failures. This includes deterministic and uniquely solvable Sudoku across 40 seeds, daily boundaries, content integrity, 400 editions of disjoint word groups, repeated letters, input parsing, score symmetry, save round-trips/corruption checks, streak behavior, spoiler-free shares and non-resettable trivia deadlines.
- `xcodebuild … build`: succeeded for iOS Simulator without signing.
- `xcodebuild … test`: six UI tests passed, zero failures. All six game screens and rules open; cryptic hints/reveal/share, three-question estimation completion, archive access, saved word validation/progress and trivia continuation were exercised.
- After the final review fixes, the full six-test UI suite passed again on the final source (150 seconds, zero failures, `build/Verified.xcresult`). This includes all six front-card states, wrap-around and tap navigation.
- Motion and formatting pass, 2026-11-02: `swift test` passed 12 of 12 and the seven-test UI suite passed on iPhone 17 Pro from a clean build (174 seconds, zero failures); the deck, six-screen and Connections/Sudoku tests also passed on iPhone 17e. Swipes in all four directions, rear-card taps, the zoom into a game, the tile reveal and the rejection shake were recorded and reviewed frame by frame. Light, dark, accessibility text size and Reduce Motion were inspected. All of this is Simulator evidence: swipe feel, haptics and frame rate have not been checked on a physical iPhone, and the iOS 17 fallback push has not been run.
- Light, dark and maximum accessibility text-size captures were inspected. The native design reviewer scored all four requested fixes resolved and returned `ship` at that fix-list scope. See `.impeccable/review/` for the actual Simulator evidence, `docs/home.png` for the final home screen, and `docs/deck-motion.mp4` for the live interaction.

- React Native port, 2026-11-02: `npm run parity` matched the Swift engine on 6,020 of 6,020 checks across 401 editions, including every Sudoku board. The typecheck and `expo-doctor` passed. On an iPhone 17 Pro Simulator in Expo Go, deck swipes in three directions, rear-card taps, Wordle, Connections, Mini Sudoku, Fermi, Krillion, Minute Cryptic, the collection and the result panel were exercised by hand, and light and dark were inspected. There is no automated UI suite for it, and it has not run on Android or a physical device.

No source-game API, live player data or backend was used. No App Store or TestFlight upload was performed. Screenshots are Simulator evidence, not renders of HTML or image mockups.
- Original looks, Zip and accounts, 2026-11-02: `npm run parity` passed 7,624 of 7,624 checks, including that every Zip edition is solvable. `npm run schema` passed 39 of 39 on embedded Postgres. All seven game screens were checked in Expo Go on an iPhone 17 Pro Simulator against the live originals, except Wordle and Connections, whose site the test browser could not open. Sign-in has not run against a real Supabase project; the Friends screens were checked with temporary sample data.
